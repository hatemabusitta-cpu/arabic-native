## 4. Double meanings, ambiguity and traps

### 4.1 Homographs without vowel marks

Unvoweled Arabic is highly ambiguous. Context normally resolves it, but **short UI strings and headlines have little context**. The classic example is **علم**:

| Voweled | Meaning |
|---|---|
| عِلْم | knowledge, science |
| عَلَم | flag |
| عَلِمَ | he knew |
| عُلِمَ | it became known |
| عَلَّمَ | he taught |
| عُلِّمَ | he was taught |

More examples a copywriter must watch:

| Unvoweled | Readings | Risk |
|---|---|---|
| **قبلة** | قِبْلة (prayer direction) / قُبْلة (kiss) | High. A prayer app or mosque-finder headline must vowel it (القِبلة) or use context like «اتجاه القبلة». |
| **ملك** | مَلِك king / مُلْك kingdom, possession / مَلَك angel / مَلَكَ owned | Medium |
| **حب** | حُبّ love / حَبّ seeds, grains / حَبّة pill, piece | «حب» in a food ad can read as "seeds" |
| **شعر** | شَعر hair / شِعر poetry / شَعَرَ felt | A shampoo campaign called «عالم الشعر» reads as "world of poetry" or "hair". This can be a deliberate pun. |
| **دين** | دِين religion / دَين debt | High in fintech: «سدّد دينك» is fine, but «الدين» alone is ambiguous |
| **جمل** | جَمَل camel / جُمَل sentences | |
| **سفر** | سَفَر travel / سِفْر a book of scripture | |
| **بر** | بَرّ land / بِرّ righteousness / بُرّ wheat | |
| **عرض** | عَرْض offer, display, width / عِرْض honor | «عروض» (offers) is safe; «عرض» alone on a sensitive topic is not |
| **خصم** | discount / opponent | «خصم 50%» is clear from context |
| **حمل** | حَمْل carrying, pregnancy / حَمَل lamb | A logistics brand saying «حمل آمن» can read as "safe pregnancy" |
| **مرة** | مَرّة once / مرّة "very" (Saudi) / مَرَة woman (Gulf/Levant colloquial, can sound dismissive) | |
| **على** / **علي** | "on" / the name Ali | Egyptian-style typing replaces final ي with ى, creating confusion |
| **مكتبة** / **مكتبه** | library / his office | Dropping the dots on ة changes meaning |

**Rule:** add only the **one diacritic that resolves ambiguity** (القِبلة، عُلِم، الحُب), or rewrite to add context. Do not fully vowel normal text.

### 4.2 الأضداد: words with opposite meanings

Classical lexicographers (الأصمعي، ابن السكيت، ابن الأنباري and others) collected words carrying two opposite meanings. Some scholars, notably ابن درستويه, rejected the category. Explanations include optimism (naming a feared thing by its opposite), sarcasm, and dialect mixing. [verified: Dorar encyclopedia, university lectures]

| Word | Meaning A | Meaning B | Modern relevance |
|---|---|---|---|
| الجَوْن | black | white | Classical only |
| القُرء | menstruation | purity between periods | Religious-legal |
| السَّليم | healthy | someone bitten by a snake (named optimistically) | |
| المَفازة | place of success | a deadly desert (named optimistically) | |
| ظَنّ | doubt, suspicion | certainty | Live: «أظن» means "I think", but in Quranic usage ظنّ can mean certainty |
| الرجاء | hope | fear (in some classical uses) | |
| شَرى / باع | sold | bought | |
| وراء | behind | ahead (Quran: «وكان وراءهم ملك») | |
| المولى | master | freed slave/client | Avoid in brand names |
| بصير | sighted, insightful | used euphemistically in Gulf speech for a blind person | Live in Gulf |
| رهيب | terrifying (MSA) | awesome (Saudi/Gulf youth) | Live and very important. In an ad for young Saudis, «رهيب» is praise. In formal MSA it means "terrible/terrifying". |
| خطير | dangerous (MSA) | amazing, "sick" (youth slang) | Live |
| فظيع | horrible (MSA) | amazing (colloquial, Levant/Gulf) | Live |

### 4.3 Polysemy that bites UI copy

| English concept | Arabic word | Other common meanings |
|---|---|---|
| account | حساب | calculation; reckoning (يوم الحساب) |
| download / load | تحميل | loading cargo; burdening |
| save | حفظ (file) | memorize (حفظ القرآن); وفّر is "save money", أنقذ is "rescue" |
| file | ملف | dossier, issue (ملف الإسكان "the housing file") |
| post | منشور | leaflet; published thing |
| platform | منصة | stage, podium |
| engagement | تفاعل | "خطوبة" is engagement to marry, a classic MT error |
| application | تطبيق (app) | طلب (job/visa application); a frequent mix-up |

### 4.4 Wordplay: جناس and تورية

- **الجناس (paronomasia):** two words with the same or similar letters and different meanings. [common knowledge]
  - *Complete* (تام): the same word with two meanings. The classic example is Quran 30:55, where «الساعة» (the Hour of Judgment) and «ساعة» (an hour) occur in one verse.
  - *Incomplete* (ناقص): one letter differs. The hadith «الخيل معقود في نواصيها الخير» plays on الخيل / الخير (horses / good).
  - **Modern slogan use** (illustrative constructions): «وفّر ووفِّ» (save and fulfill); «سهلة وسهلة الوصول»; brand names like «حرف وحرفة» (a letter and a craft). The jinas adds memorability because it echoes poetic tradition.
- **التورية (double entendre):** the speaker uses a word with a near, obvious meaning and a far, intended one. The textbook example: during the Hijra, when someone asked Abu Bakr who his companion was, he answered that this was a man who **guides him on the way** («يهديني السبيل»). The listener heard "a road guide". The intended meaning was "guides me to the path of truth". [common knowledge]
  - **Modern use:** tawriya powers clever ads and brand names. For example, a car brand might say «معنا تمشي أمورك» ("with us, your affairs go smoothly" / literally "walk"). A coffee brand might say «على كيفك» ("as you like it" / "for your mood").
  - **Risk:** a tawriya that only works in one dialect, or whose far meaning is rude elsewhere. Always check both readings in every target market.

### 4.5 Innocent in MSA (or one dialect), awkward in another

| Word | Where it is innocent | Where it causes trouble |
|---|---|---|
| **عافية** | "health" everywhere (يعطيك العافية) | Morocco/Algeria: «العافية» means **fire** |
| **ماشي** | Egypt: "OK"; Levant/Gulf: "walking" | Morocco: **"not"** (ماشي مزيان = "not good") |
| **عيش** | MSA: life, living | Egypt: **bread**; Gulf (Kuwait, Bahrain, Eastern Province): **rice** |
| **عربية** | "Arabic, Arab (f.)" | Egypt: **car** |
| **مرّة** | MSA: once | Saudi: **very**; «مَرَة» Gulf/Levant: woman (informal, can be dismissive) |
| **حرمة** | Gulf: woman (traditional) | Can sound old-fashioned or belittling to young women; avoid in ads |
| **صاحبتي** | "my (female) friend" | Egypt/Levant: often implies **girlfriend**; «صديقتي» is safer |
| **بلاش** | Egypt: "don't" or "free"; «ببلاش» means "for free" | Gulf readers may misread; «مجانًا» is safest for "free" |
| **داير** | Sudanese: "want" | MSA (دائر): "rotating" |
| **سمح** | Sudanese: "beautiful, good" | MSA: "allowed" |
| **خطير / رهيب / فظيع** | Youth slang: amazing | MSA: dangerous / terrifying / horrible |
| **تعبان** | Tired | In Gulf/Egypt also "sick, unwell" |
| **يا شيخ** | Hijazi: "really? come on!" | Others may hear a religious or tribal title |

**Brand and product names:** always run new names and transliterations past speakers of **Gulf, Egyptian, Levantine and Maghrebi** dialects. Several short Latin syllables (especially ones beginning with k- or z- and certain vowel combinations) are vulgar in one or more dialects. Do not ship a name until it has passed this check. Also check the **reverse direction**: an Arabic name in Latin letters may read badly in English or French.

### 4.6 False friends and translator traps (English → Arabic)

| English | Wrong or literal Arabic | Natural Arabic |
|---|---|---|
| Home (tab) | المنزل | **الرئيسية** |
| Feed | التغذية | **آخر المنشورات** / الرئيسية |
| Engagement (social) | خطوبة / ارتباط | **التفاعل** |
| Application (software) | طلب | **تطبيق** |
| Application (job, visa) | تطبيق | **طلب** |
| Save (money) | حفظ | **وفّر** |
| Save (file) | وفّر | **حفظ / احفظ** |
| Free (no cost) | حر | **مجاني / مجانًا** |
| Free (freedom) | مجاني | **حر / حرية** |
| Order (purchase) | أمر | **طلب** |
| Order (sequence) | طلب | **ترتيب** |
| Actually | حاليًا | **في الواقع / فعلًا** |
| Eventually | في النهاية (sometimes OK) | **مع الوقت / لاحقًا** depending on sense |
| Sensitive data | بيانات حساسة | ✔ correct |
| Feature | سمة / خاصية (sometimes OK) | **ميزة** (marketing) |
| Experience (UX) | خبرة | **تجربة** |
| Experience (job) | تجربة | **خبرة** |

| Unlock (a feature) | فتح القفل | **احصل على / افتح** |
